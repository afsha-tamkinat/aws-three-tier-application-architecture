# Three-Tier Application Architecture on AWS

## Project Overview
This project explores the design of a three-tier application architecture using AWS cloud infrastructure.

## Architecture Layers
1. Presentation Tier – User interface
2. Application Tier – Application processing
3. Database Tier – Data storage

## AWS Services and Concepts
- Amazon VPC
- Public and Private Subnets
- Route Tables
- Internet Gateway
- NAT Gateway
- Security Groups
- Amazon EC2

## Project Objectives
- Understand three-tier architecture.
- Learn AWS networking.
- Understand public and private subnet configuration.
- Explore secure communication between application layers.

## Skills Learned
- AWS Cloud Infrastructure
- VPC Networking
- Network Security
- Cloud Architecture
